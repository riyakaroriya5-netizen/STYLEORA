STYLEORA – Clothing E-Commerce Website

About the Project

STYLEORA is a modern online clothing shopping website for Men, Women and Kids.

Features

- Modern Homepage
- Product Categories
- Product Search
- Category Filter
- Price Sorting
- Product Details
- Shopping Cart
- Add and Remove Products
- Quantity Management
- Local Storage
- Checkout Form Validation
- Responsive Design

Technologies Used

- HTML
- CSS
- TypeScript
- JavaScript
- Vite
- Public API

Installation

1. Clone the repository.
2. Run npm install.
3. Run npm run dev.
4. Open the local URL in your browser.
